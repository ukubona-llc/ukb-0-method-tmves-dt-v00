You are building a [PROJECT_NAME] Digital Twin OS for [CLIENT].

PENTADIC FRAMEWORK — every feature maps to one of five layers:
  T  Tensor    — full reality. All vars, all sites, all time.
  M  Matrix    — compressed attention. What we actually watch.
  V  Vector    — gradient. Where things are drifting / worsening.
  E  Eigenmode — identity. Core patterns / DNA to preserve.
  S  Scalar    — KPI. One number with all weights baked in.
  ↺  U(s)      — the control action closing the loop.

DOMAIN
  Project : [PROJECT_NAME]
  Location: [LOCATION]
  Sites   : [N] sites across [COUNTRIES/REGIONS]
  Variables: [N_VARS] across [N_DEPTS] departments, [N_PHASES] phases
  Key risk: [PRIMARY_RISK — e.g. material leakage / cost overrun / mortality]

STATE VECTOR (per site/node, 5 dims)
  x[0] [completion / progress / health]    ∈ [0,1]
  x[1] [material / resource / data integrity] ∈ [0,1]
  x[2] [labor / capacity / staff health]      ∈ [0,1]
  x[3] [financial / supply / funding]         ∈ [0,1]
  x[4] [risk exposure / volatility / hazard]  ∈ [0,1]

TWIN EQUATION
  x_{t+1} = f(x_t, u_t, G_t)
  where G_t = network coupling across sites (same-country: w=0.15, cross: w=0.03)
  u_t = control input from dashboard sliders / CSV ingest

SCALAR KPI
  S = clip( w·x + b, 0, 1 )
  Default weights: w = [0.30, 0.20, 0.18, 0.20, -0.12], b = 0.12
  At-risk threshold: S < 0.50

LOSS FUNCTION L(θ)
  L = leakage_rate × [unit_price_field]
  By category: procured − consumed, scaled by priority weights θ
  Eigenmode breach: if λ_1 > Σ λ_{i>1} → SYSTEMIC flag

Swap these to change domain

The pentad T→M→V→E→S is universal. Only the domain vocabulary changes.

Construction (default)
sites = construction sites x[0] = % complete x[1] = material integrity L = procured−consumed categories = Cement, Steel…
Healthcare / hospital network
sites = hospitals x[0] = bed occupancy x[1] = supply chain fill-rate x[2] = staff capacity x[4] = mortality risk L = supply leakage or readmission
Supply chain / logistics
sites = warehouses/hubs x[0] = order fulfillment x[1] = inventory health x[3] = cashflow L = spoilage + delay cost
Public health / epidemic twin
sites = districts x[0] = vaccination coverage x[2] = health worker density x[4] = transmission risk R_eff coupling = population flow
Education / school network
sites = schools x[0] = enrollment rate x[2] = teacher attendance x[3] = funding stability L = dropout + absenteeism cost
Civilization stack (Ukubona full model)
Layer I = Person Layer II = Kin/Network Layer III = Systems Layer IV = Regulators Layer V = Civilization Layer VI = Portal
The six civilization layers map onto the pentad: T covers Layers I–V (the full observable reality). M selects which layer's signals to amplify. V tracks drift across layers. E preserves the identity of each layer's core function. S collapses all layers to a single decision number.
